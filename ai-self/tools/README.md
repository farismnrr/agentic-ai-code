# Local Tools

Reusable local helpers for an external MCP client live here.

Rules:
- keep tools narrowly scoped,
- avoid embedding secrets,
- provide a minimal usage note,
- add a test or deterministic validation when practical,
- register the tool in ../registry.yaml only after validation.

Frequently used helpers may later be promoted into native Masih Awam MCP tools by updating the MCP server itself.
