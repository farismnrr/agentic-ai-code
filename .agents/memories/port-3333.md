# Dev server runs on 3333, not 3000

Ports 3000, 3001, 3004, and 3100 are already bound by other services on this machine, so Nuxt's default would collide. 3333 was verified free and set as `devServer.port` in `nuxt.config.ts`.

Override per-machine with `NUXT_PORT` in `.env` — the env var wins over `devServer.port`. Don't hardcode a different port in the config; someone else's machine has a different set of collisions.
